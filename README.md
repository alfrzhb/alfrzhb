## Currently Building

### Harumnesia V2

A rebuild of the original DBS Coding Camp capstone into a cleaner and more maintainable perfume recommendation system.

The production recommender uses:

`Filtering` → `Cosine Similarity` → `Weighted Scoring` → `Diversification` → `Top Recommendations`

Built with React, TypeScript, Web Worker, and Cloudflare-oriented deployment.

[View repository](https://github.com/Harumnesia/harumnesia)

### Ratama Project & Finance Tracker

An internal project and finance tracking system covering opportunity management, project progress, invoicing, payments, and operational monitoring.

Built with Cloudflare Pages, Workers, and D1.

[View repository](https://github.com/alfrzhb/rmc)

### AI-Assisted MySQL DDL Optimization

My undergraduate thesis project for analyzing and improving MySQL DDL using generative AI.

Includes DDL analysis, SQL diff, ERD visualization, review workflow, sandbox validation, and iterative correction.

[View repository](https://github.com/alfrzhb/tugas-akhir)
